The 4 Keys to Anchoring

What it is. The four rules that make an anchor strong.

What it gives you. When you follow them, anchors work. When you skip them, anchors fade.

Steps

  1. Learn the four keys before you set any anchor.
  2. 1. Intensity: the feeling must be strong.
  3. 2. Timing: set the anchor at the peak, just before the feeling starts to fade.
  4. 3. Uniqueness: use a touch you do not use every day.
  5. 4. Replication: repeat the touch exactly the same way each time.
  6. Check every anchor against the four keys.

Time. 5 minutes to read

Words to know

Peak
The highest point of a feeling.
Replication
Doing it exactly the same way each time.

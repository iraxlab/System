Learning & Memory Tools

NLP · Learning & Memory Tools. Tools for studying and remembering.

  1. Learning Strategies · Learning in small pieces while you feel good.
  2. Spelling Strategy · Spelling by picturing the word, not by sounding it out.
  3. Memory Pegs · Remembering by placing pictures in places you know well.
  4. Sorting Patterns · Putting information into small groups so it is easy to remember.
  5. Digital Meter · Adding numbers in your head by picturing a counter that rolls on.
  6. Visual Multiplication Chart · Picturing a big times table so you can read the answers off it.
  7. Visualisation Development · Exercises to see pictures in your mind more clearly.

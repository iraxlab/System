Learning and Memory I

What it is. Memory is not one system. Declarative memory for facts and events depends on the medial temporal lobes and hippocampus; procedural memory for skills and habits depends on the striatum; working memory depends on prefrontal cortex.

What it gives you. These distinctions explain why amnesia can erase new memories while leaving skills intact, and how to support each type of memory.

Many kinds of memory

A newborn and a Nobel laureate have similar brains at the level of anatomy. The difference is largely what each has learned. Learning is the acquisition of new information; memory is its storage and later retrieval.

Declarative memory covers facts and personal events. It is fast to form and easy to lose. Nondeclarative memory includes skills, habits and conditioned responses. It forms slowly through repetition and is very durable.

Memory also moves through stages. Short-term memory lasts seconds to minutes and is easily disrupted. Consolidation then turns some of it into long-term memory, a process that can take days to years.

Where is a memory stored?

  1. In the 1920s, Lashley removed parts of rat cortex and found that maze memory faded with the amount removed, not its location.
  2. He concluded memories are spread widely, not stored in one place.
  3. Hebb proposed that a memory is a cell assembly: a group of neurons whose connections strengthen when they fire together.
  4. Penfield stimulated the temporal lobes of awake patients during surgery. Some reported vivid recollections.
  5. Today, memories are seen as distributed but relying on specific structures to form.

Neurons that fire together strengthen their connections. This principle is still central.

The patient who changed memory research

  • The surgery In 1953, at age 27, H.M. had both medial temporal lobes removed to treat severe epilepsy.
  • The result His seizures improved, but he could no longer form new declarative memories. Each day began without yesterday.
  • What remained His intelligence, older memories and ability to learn new motor skills were preserved.

He improved at mirror drawing over days while having no memory of practising.

Which region does what

  • Hippocampus Binds the parts of an event into one memory and is essential for forming new declarative memories.
  • Place cells Hippocampal neurons that fire when an animal is in a particular location, forming a map of space.
  • Diencephalon Damage to parts of the thalamus and mammillary bodies, as in Korsakoff's syndrome, also causes amnesia.
  • Neocortex Long-term store for consolidated memories, especially in the temporal lobes.
  • Striatum Supports habit learning: gradual links between a cue and a response.
  • Prefrontal cortex Holds information in working memory and organises retrieval.

The mind's scratchpad

  • Capacity Holds roughly four to seven items for a few seconds without rehearsal.
  • Prefrontal neurons Keep firing during a delay, maintaining information until it is used.
  • Area LIP Neurons in parietal cortex hold the location of a remembered target for an upcoming eye movement.

Memory systems

  • 1953 H.M.'s surgery
  • 2008 H.M. dies; his brain is studied in detail
  • 7 ± 2 items in short-term memory, classic estimate
  • 3 main systems: declarative, procedural, working
  • 1949 Hebb publishes his theory of cell assemblies
  • 1971 place cells discovered in the rat hippocampus

A Russian journalist studied for decades could recall long lists of numbers years later, using vivid mental images. His difficulty was the reverse of amnesia: he struggled to forget.

Steps

  1. Recall what you ate for dinner last night.
  2. Notice that you can describe it in words.
  3. That is declarative memory: facts and events, consciously recalled.
  4. Tie a shoelace without thinking about the steps.
  5. That is procedural memory: a skill stored as action, not words.
  6. Hold a phone number in mind for ten seconds without writing it.
  7. That is working memory: a few items held briefly for immediate use.

Time. 5 minutes

Words to know

Declarative memory
Memory for facts and events that can be consciously recalled and stated.
Engram
The physical trace of a memory in the brain.
Amnesia
Loss of memory. Anterograde amnesia prevents new memories; retrograde amnesia erases old ones.
